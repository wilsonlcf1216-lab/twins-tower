New Project / Wayfinding Prototype

CSB / HKLM / EF to IPEB Wayfinding Map

根據現有 GitHub prototype 內嘅樓層內容，建立一個獨立新 project。 呢個版本集中做 mall-style wayfinding：由 CSB、HKLM 或 EF 揀選樓層與空間， 顯示該層 floor plan、由空間行去 lift lobby、落到 2/F link bridge floor、過橋去 IPEB、 再搭 lift 去指定樓層，最後由 lift 行到目的區域。

Data Rule 原有 `index.html` 只作資料來源，本 project 唔會改動原本 dataset。

Route Steps

完整流程會跟住以下 5 個視圖同步更新。

    1. 出發層 Floor Plan

    顯示所選 building/floor 及由目標空間行去 lift lobby。

    2. 出發 Building

    顯示完整 building，並突出由當前樓層去 2/F 嘅垂直移動。

    3. 2/F Link Bridge

    顯示由出發 building 經 2/F link bridge 去 IPEB 嘅轉場。

    4. IPEB Building

    顯示喺 IPEB 由 2/F 上到目的樓層。

    5. IPEB 目的層 Floor Plan

    顯示由 IPEB lift lobby 行去指定區域。
